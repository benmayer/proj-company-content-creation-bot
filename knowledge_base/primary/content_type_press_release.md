# Press release content-type profile

Team editorial direction for press releases. Channel-specific structure lives in each `channel_*.md` file under `## Press release`. It is guidance on how to write, not a company fact.

## Voice rules

- Factual and confident; plain English, short sentences.
- No marketing filler or invented superlatives ("thrilled", "delighted", "exceptional", "unbeatable").

## Format rules

Include only dates, places, figures, quotes and calls to action that the request or the primary context supplies. Leave a clearly marked placeholder for anything missing.
