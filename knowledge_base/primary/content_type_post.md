# Regular post content-type profile

Team editorial direction for regular posts. Channel-specific rules live in each `channel_*.md` file under `## Post`. It is guidance on how to write, not a company fact.

## Voice rules

- Brutally honest, provocative and witty; self-deprecation about the low-cost reality is welcome.
- No apologies or explanatory filler.
- Prefer bold, unexpected phrasing over polished corporate language.
- One idea per post.

## Format rules

Build the post around the requested topic. Use only facts given in the request or the primary context, and do not pad it with vague claims such as "expanding our offerings".
